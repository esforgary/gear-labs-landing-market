# TG Market · интерактивное демо

Источник: https://github.com/esforgary/tg-market, commit `5c82f84`, 2026-10-16.

Все собственные файлы демо находятся в этой папке: интерфейс Telegram, магазин, модель данных, товары-иллюстрации, обложка, карточка каталога и тесты. Общий корпус телефона и блок описания используются из существующих компонентов GearLabs. В реестре каталога есть только подключения компонента/обложки; API читает `catalog.json` отсюда.

## Возможности

- Покупатель: `/start`, `/shop`, `/cart`, `/orders`, `/status НОМЕР`, `/help`, `/cancel`.
- Администратор: `/add` (название, описание, цена, изображение, цвет, остаток), `/delete` (товар или весь каталог), `/drop`, `/import` (CSV/JSON), `/orders` и изменение статуса заказа.
- `/admin` и `/customer` либо переключатель рядом с телефоном меняют демонстрационный режим. Это не авторизация.
- Заказ: новый → подтверждён → в доставке → выполнен. Отмена возвращает остаток один раз. Удаление товара не удаляет историю заказа.
- Каталог и заказы сохраняются в отдельном localStorage; «Сбросить демо» восстанавливает стартовые товары после подтверждения.

Исходный проект реализует добавление/удаление и каталог. Покупка, статусы и импорт в нём были заготовками; здесь они завершены для локальной демонстрации. Импорт принимает CSV/JSON до 1 МБ; колонки `name,description,price,image_url,color,stock`. Цена в рублях. Пустые изображение/цвет получают значения по умолчанию. Excel-файл можно сохранить как CSV.

Бэкенд, Telegram API, токены, платежи и реальные сообщения не подключаются. Используйте вымышленные контактные данные. Встроенные изображения локальные; ссылка на собственную картинку загружается браузером напрямую.
