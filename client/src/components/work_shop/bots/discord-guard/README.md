# Discord Guard

Локальное интерактивное демо бота модерации Discord на вымышленном сервере Pixel Club. Все файлы проекта находятся в этой папке; превью подключается через общий каталог GearLabs.

В роли участника (Мила) можно писать в общий канал и жаловаться на чужие сообщения. В роли администратора можно рассматривать жалобы, удалять сообщения, выдавать предупреждения, назначать или снимать тайм-аут на 10 минут, блокировать и разблокировать участников. Общий журнал сохраняет причины и результаты действий. Тайм-аут и блокировка действительно ограничивают отправку сообщений при переключении обратно на участника.

Состояние хранится в `localStorage` под отдельным ключом `gearlabs.discord-guard.demo.v1`. Повреждённые или несовместимые данные заменяются исходным демо с уведомлением в интерфейсе. Сброс возвращает вымышленных участников, сообщения и исходную жалобу. Демо не подключается к Discord, не требует токена, сервера или авторизации.

Внешнее описание, переключение ролей и управление демо переведены на все восемь языков сайта. Переписка и интерфейс внутри телефона остаются русскими.

Проверка модели из корня проекта (Node.js с поддержкой strip types):

```sh
node --experimental-strip-types --test client/src/components/work_shop/bots/discord-guard/moderation-model.test.mjs
```

Модель проверяет полномочия роли, ограничения участника, сроки тайм-аутов, дубликаты жалоб, доступность сообщений, длину ввода и целостность сохранённых данных. Изменения выполняются без мутации исходного состояния; ошибки возвращают исходное состояние.
